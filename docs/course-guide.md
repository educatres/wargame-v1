# 課程使用指引

## 建議三小時課程

### 0:00–0:20 情境簡報
- 介紹任務、角色、成功條件及安全界線。
- 各組取得不同版本的情報。
- 學生不得直接查看教師真實狀態欄位。

### 0:20–0:50 任務分析
學生回答：
1. 必須達成的核心目標是什麼？
2. 哪些是已知事實、推測及未知？
3. 對手最可能及最危險的行動是什麼？
4. 有哪些政治、民事、後勤與時間限制？

### 0:50–1:20 行動方案
- 至少提出兩個方案。
- 比較資源、風險、可逆性與後續選項。
- 決定主要方案並說明保留方案。

### 1:20–2:20 回合推演
- 每回合5–10分鐘。
- 學生提交行動、區域、資源與理由。
- 白方發布情報及事件。
- 系統結算後，教師可口頭修正或補充裁決。

### 2:20–3:00 課後檢討
- 查看決策時間線。
- 找出關鍵假設、情報落差與資源轉折點。
- 進行反事實討論。
- 完成個人反思。

## 建議分組
- 藍方：4–6人
- 紅方：4–6人
- 琥珀方：2–4人
- 白方與觀察評量：教師＋2–4人

## 評量規準
| 構面 | 比例 |
|---|---:|
| 任務與成功條件 | 20% |
| 情報與證據 | 20% |
| 資源與後勤 | 20% |
| 紅隊思維與應變 | 15% |
| 民事、法律與升級風險 | 15% |
| 課後反思 | 10% |

## 教師注意事項
- 不應將系統輸出的數字當成真實戰果預測。
- 若人工修正結果，需說明依據。
- 鼓勵學生提出「需要哪些資料才能更有把握」，而不是追求唯一答案。
- 可將同一想定用不同種子重跑，比較決策是否具有穩健性。
